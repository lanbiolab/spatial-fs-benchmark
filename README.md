# Spatial Feature-Selection Benchmark

A benchmark of expression-driven and spatially informed feature selection for spatial transcriptomics, covering spatial-signal recovery, integration, clustering and alignment.

## Overview

- Compare feature selectors across gene budgets and downstream workflows, including scVI, CellCharter and GraphST.
- Evaluate spatial recovery using simulated patterns, held-out tissue and external marker genes.
- Examine batch mixing, biological conservation, feature-count matching and computational cost.
- Explore individual-held-out validation, cross-platform comparisons and spatial aggregation.

The primary downstream analysis uses five Visium datasets. Embryo datasets and the ST, Stereo-seq and Open-ST mouse-brain comparisons are analysed separately. See [Analysis workflows](docs/analysis_workflows.md) and [CODE_INDEX.tsv](CODE_INDEX.tsv) for the corresponding scripts.

## Installation

```bash
git clone https://github.com/lanbiolab/spatial-fs-benchmark.git
cd spatial-fs-benchmark
conda env create -f environment.yml
conda activate spatial-fs-benchmark
pip install -e .
```

Method-specific dependencies are documented under `external/`. Package snapshots are available in `environments/`.

## Running the benchmark

1. Obtain the public datasets listed in `configs/datasets/` and set their local input paths.
2. Choose a benchmark configuration and adjust the output directory, feature budget, seeds and resource settings.
3. Run the configuration:

```bash
spatial-fs-run --config configs/benchmark/dlpfc_spatial_main_native.yaml
```

Use [CODE_INDEX.tsv](CODE_INDEX.tsv) to locate validation, sensitivity-analysis and plotting entry points. Configure the paths and concurrency settings in batch scripts before running them. Summary and plotting scripts consume outputs from the corresponding experiments.

## Repository layout

| Directory | Contents |
| --- | --- |
| `src/spatial_fs_benchmark/` | Feature selectors, integration wrappers, metrics and benchmark runner |
| `configs/` | Dataset and experiment configurations |
| `scripts/` | Data preparation, execution and analysis scripts |
| `analysis/` | Scoring and plotting workflows |
| `results/revision*/` | Additional validation and sensitivity-analysis scripts |
| `publication/` | Final figure rendering and panel composition |
| `tests/` | Unit tests and synthetic benchmark checks |
| `external/` | Third-party implementations and dependency references |

## Figures

Final rendering scripts are in `publication/final_main/` and `publication/final_supplement/`. [Figure_Number_Map.tsv](Figure_Number_Map.tsv) maps plotting filenames to supplemental figure numbers. Rendering requires the corresponding analysis outputs, generated by the experiment and summary scripts identified in CODE_INDEX.tsv.

The rendering workflow uses Arial, Cairo/Pango and the fractional-text helper documented with the scripts. Panel composition uses PyMuPDF.
