Notes:

- These selectors now rebuild from `adata.layers["counts"]` when available, so
  they do not double-apply `log1p` on already preprocessed datasets.
- The remaining atlas R methods are exposed through a shared `RMethodSelector`
  wrapper instead of one subprocess implementation per method.
- `TFs` now uses a local annotation-derived resource generated by
  [download_human_tfs.R](/home/xd/y/Benchmark/scripts/download_human_tfs.R),
  so it no longer depends on an external website at runtime.
- `wilcoxon` is only valid for datasets with a usable `label_key`.
- `all` is implemented as a baseline selector, but is not included in the
  default `n_features` sweeps because it does not follow the fixed-feature-count
  benchmark axis.
- A per-method smoke helper is available at
  [smoke_feature_selector.py](/home/xd/y/Benchmark/scripts/smoke_feature_selector.py).
