# Rebuild v1 frozen scoring

This document defines the scoring tables generated by
`scripts/build_frozen_scores.py`. The implementation consumes the audited merged
result table and writes one immutable set of ranges for all downstream figures.

## Metric orientation and ranges

Metrics are first oriented so that larger values always indicate better
performance. CHAOS, PAS, and Ratio are multiplied by -1; all other metrics retain
their original direction.

For each dataset, feature-selection setting, integration method, and metric, the
oriented values are averaged across available random seeds. Frozen bounds are then
computed once for each Dataset x Metric combination:

```text
Lower(d,m) = min_s mean_seed(x_oriented[d,m,s])
Upper(d,m) = max_s mean_seed(x_oriented[d,m,s])
Scaled(x)  = (x_oriented - Lower) / (Upper - Lower)
```

The range calculation includes both scVI and CellCharter and every completed
method/feature-number setting in the frozen primary matrix. GraphST and exploratory
hybrid-control values are transformed with these existing ranges; the ranges are
not recomputed after adding either sensitivity analysis. Seed-level values are not clipped. Consequently, an
individual seed may lie slightly outside [0, 1], while the setting-level seed mean
remains within the frozen range. Label-dependent ranges for unlabelled E8.5 and
E9.5 datasets are marked unavailable and are never replaced by zero.

## Task aggregation

Integration is constructed from two components:

```text
BatchMixing = mean(bASW, iLISI)
BiologicalConservation = mean(dASW, dLISI, ILL, GC)
Integration = mean(BatchMixing, BiologicalConservation)
```

For E8.5 and E9.5, BiologicalConservation is unavailable and Integration equals
BatchMixing.

Clustering is constructed from two components:

```text
LabelIndependentClustering = mean(Silhouette, oriented CHAOS, oriented PAS)
LabelAgreement = mean(ARI, NMI)
Clustering = mean(LabelIndependentClustering, LabelAgreement)
```

For E8.5 and E9.5, LabelAgreement is unavailable and Clustering equals
LabelIndependentClustering.

Alignment and aggregate scores are:

```text
Alignment = mean(Accuracy, oriented Ratio)
CoreOverall = mean(Integration, Clustering)
AlignmentEligibleOverall = mean(Integration, Clustering, Alignment)
```

CoreOverall is the primary score. AlignmentEligibleOverall is a secondary score
restricted to DLPFC and MouseBrainSerialSections, the only datasets with explicit
serial-section pairs.

## Representative settings and rankings

Representative settings are read directly from the frozen canonical configs:
most methods use N=2,000, random uses N=500, scSEGIndex uses N=500, and all_features
uses all available genes. Wilcoxon is absent from datasets without labels.

Dataset-level ranks are calculated separately for each integration method, with
rank 1 indicating the largest score. Global ranks are means of these dataset-level
ranks. Two ranking exports are provided:

- `global_method_ranks.tsv` includes selectors, controls, and the Wilcoxon
  label-informed oracle for reference.
- `global_competitive_method_ranks.tsv` includes only expression-driven and
  spatially informed unsupervised selectors. This is the appropriate table for
  statements about competitive method ranking.

Controls and Wilcoxon must not be described as ordinary unsupervised competitors.
