This archive accompanies Supplemental_Material.pdf. No separate derived-data package is submitted with this revision.
It preserves the custom Python/R implementations, configurations, analysis scripts, plotting code and available dependency/provenance records used for the original benchmark and the revision analyses. CODE_INDEX.tsv identifies the analysis entry points; MANIFEST.tsv records SHA-256 checksums for every archived payload file.

Current analysis scope
The primary downstream comparison uses five Visium datasets; the two embryo datasets are retained as separate label-independent analyses. Section- and individual-held-out validation, requested and actual-count budget comparisons, external cortical markers, fixed-budget target retention and adult mouse-brain platform extensions are covered by the revision scripts. Earlier configurations and the original benchmark README are retained to document the historical runs. For revised definitions, use the revision entry points and the accompanying manuscript/Supplemental Material, rather than the original README's seven-dataset aggregate description.

Layout
benchmark/ preserves the original project-relative paths. It contains src/, scripts/, configs/, analysis/, tests/, docs/, external/ and the relevant results/revision*/ directories. Small saved R plot objects are retained for figure regeneration. publication/ contains the final typography/spacing rendering scripts. Third-party code retains its original licenses and provenance files. The original release license is stored under benchmark/_github_release/spatial-fs-benchmark/LICENSE.

Installation and execution
1. Extract the archive and work from benchmark/.
2. Use environment.yml and pyproject.toml to construct the core environment:
   conda env create -f environment.yml
   conda activate spatial-fs-benchmark
   pip install -e .
   Method-specific dependencies and provenance are documented under external/ and in the script headers. environments/ records the installed package snapshot of the archived analysis environment; it is not a portable replacement for method-specific installation instructions.
3. Obtain raw inputs from the public accessions in the dataset configurations, the manuscript Methods, Supplemental Tables S2/S6/S7/S14/S21. Raw counts, full intermediate embeddings, feature-selection matrices and all task records are not included in this code archive.
4. Configure dataset paths for the local installation. Historical scripts preserve their original /home/xd/y/Benchmark and related paths; adapt those roots, output paths and available device/thread settings before execution. Do not launch queue/parallel scripts unchanged on a different host.
5. Run the core and revision entry points in CODE_INDEX.tsv. Many summary/plot scripts consume artifacts generated by the preceding experiments. Code is archived with its executed settings; this distribution is not a single-command reproduction container. Original run/queue scripts are retained as provenance, with final analysis paths identified in CODE_INDEX.tsv.
6. Supplemental Tables S19--S23 provide the complete count grid, ranked-gene universes, sample mapping and principal dataset-level score/rank/count summaries. Detailed machine-readable results and intermediate records are retained by the authors and are available on request. Public raw inputs must be obtained from the cited accessions.

Final figure typography
The final rendering sources are publication/final_main/ and publication/final_supplement/. They preserve the original scores and plotting objects while applying Arial typography and the final layout. final_main/compose.py records the main-panel assembly. The earlier publication/render_all_final.R and render_figure4_final.R are retained as historical steps.
The rendering scripts preserve their executed project-relative paths. Adapt the benchmark root and output locations to the extracted archive. The recorded Linux render used an installed Arial font, Cairo/Pango and a process-local LD_PRELOAD helper compiled from final_main/fractional_text.c; this helper disables integer glyph-position rounding and does not modify the installed libraries. Its library paths must match the local environment. The Windows composition step uses PyMuPDF and an installed Arial Bold font. Proprietary font files and compiled shared libraries are not redistributed. Render inputs include saved plotting objects and analysis outputs produced by the corresponding benchmark steps; the scripts are not a self-contained one-command reproduction bundle.

Validation of this archive

The complete benchmark was not rerun as part of packaging. No private-key files, access credentials, Git internals, raw subject-level data or machine-control utilities are intentionally included.
