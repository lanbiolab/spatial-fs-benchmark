# Data resources

Raw and processed spatial-expression matrices are not tracked in Git. The benchmark expects local files under `data/raw/`; YAML files under `configs/datasets/` define the paths, observation keys, coordinate keys, labels, count source, QC options, and alignment pairs.

## Public inputs

| Benchmark name | Platform | Public source |
|---|---|---|
| DLPFC | 10x Visium | spatialLIBD `fetch_data(type = "spe")`: https://research.libd.org/spatialLIBD/ |
| MouseBrainSerialSections | 10x Visium | 10x Genomics public datasets: https://www.10xgenomics.com/datasets |
| STOmics0212 | 10x Visium | STOmicsDB accession STDS0000212: https://db.cngb.org/stomics/ |
| STOmics0218 | 10x Visium | STOmicsDB accession STDS0000218: https://db.cngb.org/stomics/ |
| STOmics0224 | 10x Visium | STOmicsDB accession STDS0000224: https://db.cngb.org/stomics/ |
| E8p5Embryo | Slide-seq | GEO GSE197353: https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE197353 |
| E9p5Embryo | Slide-seq | GEO GSE197353: https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE197353 |

The three `STOmics` names reflect their STOmicsDB accessions; the matrices used in this benchmark are Visium-derived inputs rather than Stereo-seq bins. `STOmicsVisium5Samples` was excluded from count-dependent v2 downstream analyses because the available `raw_count` layer was transformed rather than non-negative integer counts.

## Tracked resources

`resources/human_tfs.tsv` contains human and mouse transcription-factor genes generated by `scripts/download_human_tfs.R` from Bioconductor `org.Hs.eg.db` and `org.Mm.eg.db` molecular-function GO annotations. Despite the historical filename, both species are present.
